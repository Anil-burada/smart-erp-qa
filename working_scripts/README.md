# Editable local scripts

Open `procurement/pi_lpo_grn.py` in VS Code and save changes before clicking
Review & Run Latest in Script Workspace. Add your future trusted scripts under
module-named folders. Every run reads the saved file and snapshots its revision.

Never put passwords or API keys in source. The dashboard can run trusted code with
your user's full permissions; do not place untrusted scripts here. Uploaded files
in the separate AI library remain analysis-only.

See START_HERE_V630.md for browser modes, credentials and reporting limitations.
